# Zapret GUI

Графическая оболочка для запуска `.bat`-сборок [zapret](https://github.com/bol-van/zapret)
(например, [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)).
Запуск и остановка одной кнопкой, автоподбор рабочей стратегии, скачивание и обновление
сборки прямо из программы.

> **Неофициальный проект.** Он не связан с авторами zapret и сборок и не содержит их кода:
> нужная сборка скачивается с GitHub по твоей команде.

## Возможности

- **Старт / стоп** выбранного батника (стоп убивает `winws.exe` и пробует остановить драйвер WinDivert),
  индикатор статуса и аптайм.
- **Автоподбор стратегии.** Батники запускаются по очереди, и для каждого параллельно проверяется
  доступность YouTube: страница, картинка и CDN с видео. На стратегию уходит около 5–7 секунд,
  можно остановиться на первой рабочей. Перед проверкой идёт контрольный прогон без zapret:
  если всё и так открывается (VPN, другой обход), программа об этом скажет. Список проверок
  редактируется в настройках (можно добавить Discord и т. д.).
- **Скачивание и обновление zapret** из релизов официального репозитория Flowseal: прогресс,
  отмена, проверка SHA-256 (если GitHub её отдаёт), защита от path traversal при распаковке.
  Пользовательские списки (`*user*.txt`) переносятся в новую версию.
- **Несколько сборок.** Видит версии, скачанные через GUI, добавленные вручную папки и найденные
  на компьютере (кнопка «Найти на компьютере»). Внешние сборки можно только убрать из списка, файлы
  на диске программа не удаляет.
- Трей, автозапуск GUI при входе в Windows (через планировщик задач, без UAC-запроса),
  запуск последней стратегии при старте, светлая и тёмная темы, лог.

## Установка и запуск

Нужны Windows и Python 3.10+.

```bat
git clone https://github.com/<твой-ник>/zapret-gui.git
cd zapret-gui
pip install -r requirements.txt
python zapret_gui.py
```

Программа сама перезапустится с правами администратора: они нужны, чтобы `winws.exe`
мог загрузить драйвер WinDivert. `pystray` и `Pillow` нужны только для иконки в трее;
если их нет, программу можно поставить и без них, а трей включится позже кнопкой в настройках.

Данные хранятся в `%LOCALAPPDATA%\ZapretGUI`:

| Что | Где |
| --- | --- |
| Настройки | `config.json` |
| Лог | `gui.log` |
| Скачанные сборки | `versions\<версия>\` |

## Разработка

```bat
pip install -r requirements-dev.txt
python -m pytest
```

Логика вынесена в `zapret_core.py` и не зависит от GUI, поэтому тестируется без Windows:
конфиг, установка и обновление, сравнение версий, поиск сборок, сценарии автоподбора.
Интерфейс лежит в `zapret_gui.py` (customtkinter).

### Сборка exe

Готовый `ZapretGUI.exe` появляется в разделе **Releases**: его собирает GitHub Actions
(`.github/workflows/release.yml`) при пуше тега вида `v*`:

```bat
git tag v1.0.0
git push origin v1.0.0
```

Собрать локально (Windows, Python 3.10+):

```bat
build_exe.bat
```

Результат: `ZapretGUI.exe` в корне проекта (копия лежит в `dist\`). Иконка берётся из
`assets/icon.ico`; перерисовать её можно скриптом `python tools/make_icon.py`. В exe уже
вшит запрос прав администратора, вместе с релизом
публикуется файл `.sha256`. Exe не подписан, поэтому SmartScreen и антивирусы могут
предупреждать; сборки PyInstaller вообще нередко дают ложные срабатывания.

## Важно знать

- Антивирус может ругаться на `winws.exe` и WinDivert. Это известное ложное срабатывание,
  но решение об исключениях остаётся за тобой.
- Скачивай сборки только из официального репозитория (адрес зашит в программе). Клонов с
  похожими названиями много, и часть из них подделки.
- Без доступа к GitHub скачивание не сработает. Тогда укажи уже имеющуюся папку со сборкой.
